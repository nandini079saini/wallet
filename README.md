# Wallet App

A full-stack personal finance tracker that allows users to manage expenses, income, bills, and receipt scanning with OCR support.

## Live Demo

Frontend: https://wallet-app-tracker.netlify.app
Backend: https://wallet-backend-op4d.onrender.com


## Features

* User authentication with JWT
* Add and manage expenses
* Add and manage income
* Monthly bill tracking
* OCR-based receipt scanning
* Expense analytics dashboard
* Email bill reminders
* Responsive UI
